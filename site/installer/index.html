  1. Prepare

      {{requires}}

    Close other MIDI software, keep the FM-1 powered throughout, and keep the recovery notes open in another tab.

  2. Connect to the FM-1

    Connect it by USB and switch it on. Your browser will ask to allow MIDI: allow it. This only asks the FM-1 what it is running. Nothing is written.

    No device connected.

  3. Confirm

    EXPERIMENTAL FIRMWARE

    CLATTER Pocket has passed emulator testing but has not yet been verified on physical hardware.

    Installing it replaces the FM-1’s stock instrument firmware.

    There is a risk of installation failure, loss of settings or requiring firmware recovery.

  4. Install

    Do not unplug, close this page or let the computer sleep until it says it has finished. It finishes only when the FM-1 has restarted and reports this exact build.

    Keep this page open. Reconnect the same FM-1, then press Connect and Install again: the updater resumes from its loader. If that does not work, follow the recovery notes below.

    Now run the first hardware test. Follow FIRST-HARDWARE-TEST.md from First boot, and stop if any of its stop conditions happen.
